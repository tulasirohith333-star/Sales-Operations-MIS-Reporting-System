# Sales & Operations MIS Reporting System

## Project Overview

The Sales & Operations MIS Reporting System is a data analysis and reporting project built using Microsoft Excel and MySQL.

The project uses a realistic sales and order dataset to demonstrate the complete process of data cleaning, data consolidation, SQL analysis, and MIS reporting.

The objective is to transform raw sales data into meaningful business reports that can help understand sales performance, product performance, customer activity, regional performance, and order status.

---

## Objectives

- Clean and validate raw sales data
- Identify and remove duplicate records
- Handle missing values
- Store and analyze sales data using MySQL
- Use SQL queries to answer business questions
- Generate business insights from sales and order data

## Dataset

The project uses a realistic sales and order dataset containing information such as:

- Order ID
- Customer ID
- Customer Name
- Product ID
- Product
- Category
- Region
- Order Date
- Sales Channel
- Quantity
- Unit Price
- Sales Amount
- Payment Status
- Order Status

The dataset contains multiple customers, products, regions, sales channels, order dates, payment statuses, and order statuses.

The raw dataset also contains intentional data-quality issues for demonstrating data cleaning.
